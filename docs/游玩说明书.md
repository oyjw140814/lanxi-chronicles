# 岚汐纪：潮晶之争 · 游玩说明书

适用版本：本项目第一阶段可玩版本。以 `scripts/game_data.gd` 与当前游戏行为为准。

## 1. 游戏目标

风暴之后，岚晶再次在群岛发出微光。你将率领**雾岸同盟**，与**赤铜远征队**争夺潮晶航线。双方从地图两侧出发，发展经济、建设营地并指挥军队交战。

本作是一张地图、一个玩家阵营对一个 AI 阵营的单人即时战略游戏。**摧毁敌方回响心即可胜利，自己的回响心被摧毁则失败。** 无需消灭地图上所有敌人。结算后世界停止推进，可查看结果并重新开始。

一局的基本顺序是：采集 → 建造 → 训练 → 探索 → 交战 → 补充经济与军队 → 攻击敌方基地。AI 也要采集和支付成本，会持续发展并逐步加大进攻力度。

## 2. 首次启动与界面

打开项目启动器，或使用 Godot 运行项目，点击“启程 · 新的战局”。新的战局自动显示八步引导。

- 顶栏：穗粮、枝材、岚晶、当前人口/人口上限、比赛时间和菜单入口。
- 左侧引航手册：当前教学目标；可点击“跳过”。
- 底部：选中对象、生命或施工/生产信息、相关建造和训练按钮。
- 底部常用按钮：快速选中工人或军队、招募中心、回营、停止、多选、镜头缩放。
- 右下海图：观察已探索区域与单位位置；点击海图将镜头移到对应位置。
- 临时提示：解释资源不足、无效位置、建筑完工、生产完成和敌军集结等情况。

建筑与单位不仅用颜色区分阵营，也使用圆环、方形和不同结构轮廓。选中单位出现选择光环。选中或受伤的单位与建筑显示头顶血条，低于一半生命变为金黄，低于四分之一变为红色；缩放镜头时血条保持可读大小。工人底栏会显示采集、运输、施工或待命状态。

建议电脑先用“均衡”画质，低性能设备先用“流畅”。“精致”保留更完整的场景装饰与阴影。可随时从菜单进入“航行设置”，调整画质、总音量；桌面版可切换全屏。

## 3. 电脑操作

下表中的快捷键在游戏窗口获得焦点、战局未被菜单遮挡时使用。

| 操作 | 方法 |
|---|---|
| 选择对象 | 左键点己方单位或已完工建筑；未选部队时可点选资源、敌人查看信息；已有部队时 Shift + 点击查看 |
| 框选己方单位 | 在战场按住左键拖出方框 |
| 添加/取消单个选择 | Shift + 左键；也可打开“多选”后逐个点选 |
| 添加框选结果 | Shift + 拖框 |
| 移动 | 先选择单位，再普通点击空地；也可点“移动”后点目的地，或右键空地 |
| 采集 | 点选拾光者，再普通点击风铃木、穗果丛或岚晶矿；也可点“采集”后点资源，右键同样有效 |
| 攻击指定敌人 | 选择部队，再普通点击当前可见的敌军或敌方建筑；右键同样有效 |
| 攻击前进 | 按 A，或点部队指令卡“沿途迎击”，然后左键点击目的地；沿途发现敌人会交战 |
| 停止当前命令 | S，或底部“停止” |
| 移动镜头 | 方向键、鼠标中键拖动、触控板双指平移手势，或点击海图 |
| 缩放镜头 | 鼠标滚轮、触控板双指捏合手势，或底部 − / + |
| 镜头回营 | H，或底部“回营” |
| 建造风栖居 | 选中拾光者，按 B，再左键选择建造地点 |
| 建造其他建筑 | 选中拾光者，点击建筑卡片，再左键空地 |
| 继续未完工建筑 | 选中拾光者，普通点击己方未完工建筑；右键同样有效 |
| 创建编队 | 选中己方单位，Ctrl + 1…5；macOS 也支持 Command + 1…5 |
| 选择编队 | 1…5；不会自动移动镜头 |
| 快速选工人/军队 | 底部“工人”或“军队”，选择全地图对应己方单位 |
| 打开说明书 | F1，或菜单“引航手册” |
| 手动存档 | F5，或菜单“保存进度” |
| 读取存档 | F9，或菜单“读取存档” |
| 暂停 | 空格，或菜单按钮 |
| 取消/暂停 | Esc 先取消当前放置、命令或多选状态；没有这些状态时打开暂停菜单 |
| 取消建筑放置 | 右键、Esc，或“取消放置”按钮 |
| 取消采集/移动/沿途迎击的目标选择 | 右键、Esc，或“取消指令”按钮 |

笔记本不必接鼠标：**点工人 → 点树、果丛或矿石**即可采集。开着“多选”时点击只用于选择，请先关闭它再下令；Shift 同样用于选择，不会下令。指令卡超出底栏时，可横向滚动查看。点“采集”后误点空地会显示提示并继续等待资源目标。触控板手势是否由系统传递取决于设备与系统设置，也可使用方向键、海图和 − / + 完成镜头操作。

**“回营”只移动镜头，不会召回部队。** 普通移动命令用于确定地走到目的地；希望沿途自动迎敌时使用攻击前进。部队闲置时会自动与附近可见敌人交战，工作中的拾光者会优先执行采集或施工命令。

## 4. 手机与平板操作

请横屏游玩。点选单位后，点空地移动、点资源采集、点可见敌人攻击；点己方未完工建筑可以派选中的拾光者继续施工。点己方已建成建筑会选中建筑并显示可用功能。

| 操作 | 触控方法 |
|---|---|
| 单选 | 点一下己方单位或建筑 |
| 多选 | 打开底部“多选”，连续点单位，或拖框添加多个单位；再次点“多选”关闭 |
| 快速选取 | 使用“工人”“军队”按钮 |
| 移动/采集/攻击 | 先选单位，再点对应空地、资源或敌人 |
| 攻击前进 | 选中军队 → 点“沿途迎击” → 点目的地 |
| 移动镜头 | 关闭多选后，单指拖动战场 |
| 缩放及平移镜头 | 双指捏合/张开，并移动两指中点；也可使用 − / + |
| 移到地图某处 | 点右下海图 |
| 建造 | 选拾光者 → 点建筑卡片 → 点空地 |
| 取消建造预览 | 点“取消放置” |
| 生产 | 选建成的回响心或织锋庭 → 点单位卡片 |
| 暂停/保存/说明 | 点顶栏菜单，再选择相应项目 |

多选开启时，单指拖动的含义是框选；关闭多选后才是移动镜头。双指操作结束后不会补发单指移动或攻击命令。横屏转竖屏时显示旋转提示，并暂停战场推进与指令；旋回横屏后可以继续。切到后台或其他应用时会保存并暂停，返回后从暂停菜单继续。

触控逻辑已在工程中实现。当前交付尚未完成 iOS/Android 安装包的真实设备验收，不能将桌面模拟手机尺寸视为手机实测。

## 5. 资源、采集与人口

| 资源 | 来自 | 主要用途 |
|---|---|---|
| 穗粮 | 穗果丛 | 工人、军队、织锋庭和科技 |
| 枝材 | 风铃木 | 建筑、武器、军队和科技 |
| 岚晶 | 岚晶矿 | 裂岩兽、辉棱哨和科技 |

每局双方各有穗粮 **280**、枝材 **340**、岚晶 **140**。玩家初始拥有 **4 名拾光者、1 名棱盾卫、1 名弦光手和1座回响心**；AI 初始兵力相同。

拾光者先走到资源旁采集，每次动作约 0.7 秒获取 2 份，最多携带 **12 份**。背包满后自动返回回响心，只有完成交付，顶栏资源才增加，随后回到原采集点。运输距离会影响实际每分钟收入。风铃木和穗果丛各存有 650 份资源；每个岚晶矿存有 900 份。

可以为不同工人分配不同资源。携带一种资源时改派另一种资源，工人会先交付已有资源，再开始新任务。节点耗尽后会寻找同类资源；如果道路不可达或资源太远，请手动改派到附近可见节点。拾光者阵亡时未交付的资源不会入库。

每个单位占 **1 人口**。回响心提供 **10** 人口，建成的风栖居每座增加 **6**，全局人口上限最多 **80**。生产队列中的单位提前占用人口，所以画面上的人数可能少于顶栏“已用人口”。未完成的住宅不提供人口，住宅被摧毁会降低上限；上限不足时，已有生产可能等待新的住宅完工。

## 6. 建筑与施工

建造顺序：选中至少一名拾光者 → 选择建筑 → 在当前可见的空地放置。费用在放置成功时一次扣除，随后工人前往现场施工。多名工人同时施工会加快进度；表中为一名工人在现场连续工作的时间，不包括走路。

建造位置必须留出建筑、资源和地图边缘的间距；红色预览表示不可放置。可以在施工途中改派工人，建筑会保持现有进度。要恢复施工，重新选工人并指向未完工建筑。

| 建筑 | 穗粮 | 枝材 | 岚晶 | 生命 | 单工人施工 | 视野 | 功能 |
|---|---:|---:|---:|---:|---:|---:|---|
| 回响心 | — | — | — | 1200 | 初始建筑 | 17 | 资源交付、招募全部6种职业、科技、10人口；不可重建 |
| 风栖居 | 0 | 70 | 0 | 400 | 14秒 | 9 | 增加6人口 |
| 织锋庭 | 40 | 140 | 0 | 650 | 22秒 | 12 | 训练盾卫、射手、枪卫、骑士、攻坚兽 |
| 辉棱哨 | 0 | 100 | 60 | 540 | 20秒 | 16 | 自动攻击附近可见敌人 |

视野以游戏世界距离为单位。未完工建筑的视野减半。辉棱哨基础攻击 **20**、攻击间隔 **1.6 秒**、基础射程 **11**；目标自身大小会影响实际接敌距离。

当前版本没有维修、拆除返还或取消生产退款功能。生产建筑被摧毁，其队列也会损失，优先保护回响心和正在生产的织锋庭。

## 7. 单位、生产与战斗

点底部 **“招募”** 打开位于屏幕中央的回响心招募面板，或选中生产建筑点击“招募中心”。回响心可训练全部6种职业；织锋庭可训练5种战斗职业，具有独立队列。每种职业都列出用途、生命、攻击、射程、训练时间和费用。点击“招募工人 / 射手 / 骑士”等按钮会立即扣除穗粮及其他所需资源并入队；每座建筑最多排队 **5 个**，每名单位占1人口。招募面板内战局暂停，点击顶部“返回战场”后继续训练。失败原因显示在面板内，不会错误扣费。生产完成后单位出现在建筑附近。底栏显示队首进度及队列数量。

| 职业 | 具体用途与弱点 |
|---|---|
| 工人 · 拾光者 | 采集三种资源、搬运交付、施工；战斗力弱，留在营地或受保护的资源点。背包有货时显示物资模型。 |
| 盾卫 · 棱盾卫 | 近战前排与保护后排，抵住敌人并压制射手；提防攻坚兽。 |
| 射手 · 弦光手 | 7米远程输出、在盾卫后方支援、克制攻坚兽；被骑士或盾卫近身时应转移。 |
| 枪卫 · 缚潮枪卫 | 长枪反骑兵，守住路口、保护射手侧翼；移动慢，适合提前布防。 |

| 攻坚兽 · 裂岩兽 | 高生命的重型拆建筑单位，对建筑伤害高；行动缓慢，需盾卫及射手护送。 |

推荐从工人维持经济、盾卫配射手开始，再根据敌军阵容补枪卫或骑士；进攻基地时加入攻坚兽。

单位会绕开建筑和资源，并尽量彼此避让。拥挤时可以把大队分成两组，指向更宽的空地。攻击目标消失或离开视野后，部队会停止追踪实时位置，向最后看到的区域继续探索或恢复待命。

## 8. 科技：潮晶共鸣

选中回响心，点击“潮晶共鸣”。花费**穗粮 100、枝材 100、岚晶 60**，立即完成，每个阵营只能研发一次。

- 己方单位和哨塔攻击力提高 **25%**。
- 拾光者采集动作速度提高 **20%**；搬运距离和移动速度保持原值，所以整体经济收入不会固定增加20%。
- 兵种克制与科技效果相乘。例如裂岩兽拆建筑的单次伤害从60增加到75。

## 9. 探索与敌方 AI

玩家从地图西南侧出发，敌方回响心位于东北侧。世界范围为80×80，右下海图的北方箭头帮助辨认方向。

深色区域表示尚未探索。探索过但没有己方实时视野的位置会变暗；敌人只在当前可见范围内显示，不能隔着迷雾持续跟踪。建造需要当前视野，仅“曾经探索过”不够。

默认采用 **休闲** 人机，可在菜单“航行设置”切换。两种难度仍使用实际的采集、费用、施工、队列与人口规则。

| 规则 | 休闲（默认） | 标准 |
|---|---|---|
| 首次主动出征 | 不早于8分钟 | 约90秒 |
| 出征间隔 | 至少150秒 | 约80秒 |
| 每波上限 | 12分钟前2人，18分钟前3人，此后4人 | 3分钟前2人、5分钟前4人，此后7人 |
| 战斗部队总量限制 | 12分钟前6人，此后10人 | 24人 |
| 敌军伤害 | 基础规则的70% | 基础规则的100% |
| 敌方科技与精锐 | 12分钟后才研究；此前不生产骑士与攻坚兽 | 更早发展与生产 |

休闲模式给你时间采集、建设和试用招募中心，**敌营仍会自卫**；主动深入敌营可能提前交战。实际出征还取决于可用兵力。切换到休闲会让已出征部队回营，至少留出3分钟准备；已经选择休闲时重复点击不会重置进攻计时。难度随存档保存，不含难度信息的旧存档读取时会迁移到休闲并给出准备时间。

敌军首次进入己方视野时，屏幕边缘出现缓慢的琥珀色警示、合成提示音及右上角“敌军进入视野”提示，持续约7秒。点击提示可将镜头移至发现位置。警报不会透视迷雾；同一批持续可见敌人不会反复报警，警报间隔至少12秒。收到集结提示后，也可按H检查基地。

## 10. 八步教学

新局自动开启教学，左侧显示当前步骤：

1. 认识目标和界面，找到自己的营地。
2. 选择一名拾光者，或使用“工人”按钮。
3. 下达采集指令，等工人真正运回第一批资源。
4. 建造并完成织锋庭。
5. 从织锋庭训练战斗单位。
6. 派部队揭露更多未知区域。
7. 指挥一次与可见敌人的战斗。
8. 继续发展与进攻，摧毁敌方回响心。

教学主要根据实际操作与世界状态推进；只点按钮但没有足够资源、没有完工或没有交付物资，不会完成相应目标。引导不会冻结敌方发展，随时可以暂停思考。

点“跳过”可以隐藏引导。菜单里的“重新开启教学”会再次显示引导；它不会自动清除当前战局。如果要从初始资源和建筑重新练习，请使用“重新开始战局”。

## 11. 推荐的新手流程

第一分钟，安排工人分头采穗粮和枝材，抽出工人建织锋庭。不要长期把所有工人留在空地。新工人可以逐步增加到6至8人，其中1人采岚晶，其他人负责穗粮和枝材。

织锋庭完工后先补棱盾卫和弦光手，人口接近上限就建风栖居。留意AI的集结提示，让已有单位靠近营地前沿，不要把所有工人送去侦察。

有稳定收入后加入裂岩兽。凑齐约5至8个互相配合的战斗单位，使用攻击前进探索东北。优先处理敌方守军，再用裂岩兽攻击回响心，同时继续从基地生产补充单位。

这是帮助理解循环的建议，并非固定通关脚本。地形、指挥方式、单位组成及进攻时机会影响结果。

## 12. 暂停、存档与恢复

菜单、说明书和设置会暂停比赛。回到战局前点击“继续战局”。按H只是查看营地，不会改变游戏时间。切入后台会暂停并尝试自动保存；返回时从暂停菜单恢复。竖屏提示期间也不会推进比赛。

| 数据 | 文件 | 写入时机 |
|---|---|---|
| 手动战局存档 | `user://campaign.json` | F5 或“保存进度” |
| 自动战局存档 | `user://autosave.json` | 比赛实际运行约每60秒，以及切入后台时 |
| 用户设置 | `user://settings.cfg` | 画质、音量等设置改变时 |

`user://` 是 Godot 的用户数据目录，macOS 默认位于 `~/Library/Application Support/Godot/app_userdata/岚汐纪/`。Windows 和手机使用各自的应用数据目录，可在Godot运行环境查询 `OS.get_user_data_dir()` 获取准确位置。

存档包含双方资源、单位和建筑、当前命令、生产队列、科研、迷雾、AI计时、镜头和教学进度。**当前选择与1至5编队不会保存，读档后需要重新编队。** 保存先写临时文件，成功后替换原文件；读取会校验格式，损坏或不兼容的文件会提示失败。

普通读取优先使用手动存档；不存在手动存档时使用自动存档。读取会替换正在进行的战局，重新开始则建立全新的初始战局。建议在尝试新策略前手动保存一次，并保留需要的存档备份。

## 13. 常见问题

**资源没有增加。** 工人仍在赶路或背包里尚未交付。选中工人查看携带数量，确认有可到达的回响心，并给工人分配附近资源。

**建筑放不下。** 地点可能被建筑或资源占用，距离边缘太近，或当前没有视野。把预览移到宽阔、明亮的空地。资源不足时提示会列出缺少的种类和数量。

**点了生产没有立刻出现单位。** 生产有时间和队列，且预占人口。选中生产建筑查看进度；建筑需要先完工，住宅被摧毁后可能需要补建人口容量。

**手机点空地只是在选取。** 先确保选中了己方单位；关闭“多选”后再点目标。多选开启时，点击和拖动用于组织选择。

**部队不前进或没有打到目标。** 目标可能已消失、进入迷雾，或者路线拥挤。重新指定宽阔目的地，必要时拆成两队。工人不会自动放弃经济工作去远处战斗。

**切换窗口后比赛停了。** 这是后台暂停机制，返回游戏并点击“继续战局”。窗口变成竖屏时先旋回横屏。

**从 Godot 启动时如何缩放窗口？** 当前项目点击编辑器的运行按钮后，会打开独立游戏窗口并默认最大化。还原窗口后可自由调整尺寸，界面与战场会同步适配。更新前的旧运行进程需先停止；如果仍看到固定尺寸的嵌入预览，请重新打开项目以加载最新启动配置。无需修改编辑器预览菜单。

**窗口变化后难以找到按钮。** 紧凑界面收起次要说明。选工人后点「建造」查看建筑；点「海图」展开或收起小地图。电脑的建筑与生产指令使用网格排列，手机的核心指令直接可见；长列表与说明可以纵向滚动。「菜单」按钮始终单独保留。当前需要横屏；小于 480×320 逻辑尺寸时会暂停并显示放大窗口提示。

**画面卡顿。** 先换“流畅”档，关闭其他占用较高的应用，避免短时间聚集大量单位。实际帧率取决于硬件；尚未承诺所有手机30FPS或所有电脑60FPS。

**没有声音。** 检查游戏音量滑杆、系统音量和输出设备。游戏配有程序合成的氛围音乐与操作/战斗提示音，没有配音。

**找不到存档或存档损坏。** 确认使用同一台设备和同一用户数据目录。首次新局需要经过自动保存时间或手动保存；不要在编辑存档后覆盖唯一备份。存档失败时检查存储空间及权限。

## 14. 当前范围与限制

当前内容为单张原创地图、单人对AI、四类建筑、工人及三类战斗单位、一次科技、教学与本地保存。没有多人联网、战役选关、外交、船只、账号同步、维修、生产取消、内购或排行榜。

模型与声音为当前工程的原创程序化制作。Houdini资产制作接口另附，但本机尚未安装Houdini，不能将现有画面描述为已在Houdini内制作和验证。桌面窗口尺寸检查也不代表手机安装、触控硬件、温控、电池或商店发布已通过验收。


## 字号与高 DPI 显示

默认正文 18、辅助文字 16、按钮 18–20 个逻辑单位。在「航行设置 → 画面与文字」选择「正常」或「大字 · 125%」，偏好会保存在本机，重新启动后保留。Retina 等高 DPI 屏幕按系统比例渲染；大字模式会同步调整布局，长内容滚动查看。触控区域至少 48×48 个逻辑单位。

Godot 编辑器启动与独立 App 使用相同规则。更新代码后，请先停止旧的运行实例，再点击右上角启动；已运行的游戏不会自动加载全部新界面代码。窗口可玩下限 480×320 指逻辑尺寸，例如 2 倍密度屏幕对应约 960×640 实际像素。低于下限或竖屏会暂停并显示提示。


## 采集音效

拾光者在资源旁实际采集时会发出对应的柔和声音：摘果子是轻轻的果实摘取声和叶片沙沙声，伐木是低沉温润的木头敲击声，采矿是短促柔和的晶石声。每类声音有细微变化；工人走路、返回交付或资源耗尽时不会继续触发采集声。

只播放附近、画面内可见的己方采集声音，远处逐渐减弱。多名工人同时工作时会自动控制播放密度。进入暂停菜单、招募或竖屏提示后采集音停止，回到战场后随实际动作恢复。声音跟随「设置 → 音量」调整，音量为零时静音。
