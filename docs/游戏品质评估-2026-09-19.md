# 岚汐纪：潮晶之争 · 游戏品质评估

评估日期：2026-09-19。目标基准为完成度较高、可以持续游玩的精品单人即时战略游戏。优先级按当前项目收益排序，P0 为下一轮优先改善，P1 为正式完整版本的重要建设，P2 为定位确定后选择扩展；不代表所有条目都是程序错误或所有游戏必须具备。

当前版本已经具备真实采集与运输、施工、生产队列、人口、六种单位、兵种克制、战争迷雾、AI、胜负、八步教学、手动和自动存档、五组编队、攻击前进、触控逻辑、血条、敌人出现警报和采集音效。整体判断是“基础循环完整的单人 RTS 可玩版本”，距离精品成品的差距主要在操作效率、策略变化、内容量和视听打磨。

本次直接检查源码、在隔离副本运行现有原生界面与集成检查，并查看新生成的截图。没有更改游戏实现或玩家存档，没有进行人工完整通关、长期性能测试、物理扬声器试听或手机真机测试。

## P2：按产品定位选择

| 功能 | 何时值得做 |
|---|---|
| 多人对战、合作模式、观战、回放、匹配/断线恢复 | 若目标是长期竞技或合作RTS，优先级会上升；纯单人精品不以联机为必要条件。确定做联机时应及早规划指令同步与确定性。 |
| 成就、挑战关、每日/每周目标、图鉴 | 基础关卡和战斗足够好玩以后，为重复游玩提供目标；无需强行加入日常任务。 |
| 地图编辑器、Mod、创意工坊 | 有足够基础内容和玩家群体之后，用于延长内容寿命。 |
| 云存档、多语言、平台成就 | 根据发行平台和市场决定，先建立稳定存档格式和可本地化文本。 |
| 昼夜、天气、海战、英雄技能、超大规模战斗 | 只有能够服务核心玩法时再做；天气与光追不是“高端”的通用门槛。 |

账号、内购、商城、赛季通行证均不是当前单人游戏的品质必备项。
