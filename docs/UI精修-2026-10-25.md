## 完成内容

- 统一深海青、雾青、黄铜、象牙白、灰绿与珊瑚警报色；切角面板和分层按钮使用集中式视觉样式。
- 原创资源／操作图标 26 个；从既有模型渲染透明缩略图 10 张。缩略图为离线纹理，不持续渲染额外 3D 视口。
- 桌面指令改为网格，常用操作不再依赖横向滚动；手机提供建造面板、单位详情和可折叠海图，核心指令与 48×48 以上点击区域保留。
- 首页隐藏战斗 HUD，采用场景背景、徽记、简短文案与菜单。暂停、设置、说明、结算、竖屏提示统一样式。
- 设置分为画面与文字、声音、难度；正常字号和 125% 大字模式同步重排。偏好保存在 settings.cfg 的 display/large_text，旧配置默认正常字号。
- 招募采用兵种卡片，费用和详情可见；顶部资源／人口／队列／反馈固定，连续招募只更新状态，保留滚动与已展开卡片。
- 教学详情可展开；弹窗返回入口固定。从战场直接打开说明后可以返回战场，不再误入首页。
- 按钮包含普通、悬停、按下、选中、禁用、焦点及危险操作状态。按下反馈约 100ms，弹窗淡入约 140ms；设置选项带选择标记。

## 复现

使用 README 中的 Godot 可执行文件，分别运行：

```sh
Godot --headless --path . --script tests/window_layout.gd
Godot --headless --path . --script tests/sim_test.gd
Godot --path . --script tests/ui_refinement.gd
Godot --path . --script tests/ui_interaction.gd
```

`ui_refinement.gd` 可追加 `-- --baseline-hud=/absolute/path/to/old/hud.gd` 输出旧 HUD 的同场景截图；之后用带 Pillow 的 Python 运行 `tools/make_ui_comparisons.py`。
